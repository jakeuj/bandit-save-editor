# 依遊戲程式建立存檔知識

需求類型：新功能。使用者已於本次對話確認完整計畫並要求實作。

## 為什麼做

現有修改器只有資源與材料，其他欄位多依座標顯示。需要從遊戲事件與資料表取得可追溯規則，讓角色、職業、技藝及山寨資料可理解、可驗證地編輯。

## 要改什麼

- 建立可重跑解析工具，整理 22 層存檔、來源指紋、欄位讀寫與規則證據。
- 擴充型別化欄位、名稱、經驗聯動、精確匯出及語意比對；保留原有 API、手動座標與單檔離線使用。
- 新增角色養成、山寨科技、物品裝備及欄位圖鑑。未核實或未通過遊戲驗證的寫入維持唯讀。
- 使用獨立測試副本，不修改正式存檔；測試 Steam 寫入只落在本機。
- 驗證後更新說明、共用技能並發布 GitHub Pages。

## 影響範圍

`index.html`、`tests/`、`scripts/`、`knowledge/`、`docs/research/`、README 與 Pages workflow；共用技能正本依已授權計畫更新。
