# 第二批研究任務

本輪交付為靜態研究與驗證計畫。下列待辦是後續研究檢查點，不表示已授權或完成新功能實作。

- [x] 1. 補充技能中的 BOM、PWA 指紋及驗證範圍維護知識。
- [x] 2. 核對品質、原始品質及詞條的來源、值域與生命週期，記錄候選範圍與未確認項目。
- [x] 3. 核對丹藥增量單位、服藥限制、重生及衍生效果，記錄候選範圍與未確認項目。
- [x] 4. 整理各群組一般／超限與後續原生操作的遊戲驗證矩陣。
- [ ] 5. 實作前決定品質升降時詞條與既有裝備等級的處理策略、y23 語意、飛升判定、復原群組與公開範圍；丹藥選定直接指定或模擬服藥語意。
- [ ] 6. 實作前補齊所用資料表的指紋覆蓋，列出每項待驗案例與具體預期值。

## 驗收條件

- 研究交付：每項結論能回查原版 SID、expression 或表格欄位；推論與產品建議清楚標示，沒有將靜態分析寫成遊戲驗證成功。
- 研究交付：列出有效／無效實體、升降、槽位／係數、原版邊界、超限及重生等情境；未確認處有可執行的下一步。
- 後續開放：每個群組以相符來源在 repo 外完成載入、原版存檔、停止、新 PID 重啟與原始存檔雜湊核對；後續操作通過才開對應閘門。
- 後續開放：合成測試覆蓋非法輸入、交易失敗回滾、累計還原、具名操作與自訂座標一致限制；預覽及匯出只包含允許欄位。
- 後續 UI：桌面、390px、PWA 離線與單檔直接開啟各自記錄。工具不允許的直接開檔驗收保留待辦，不以其他結果替代。
