# 山寨帳房 v2.1 進階修改

需求類型：新功能。使用者已確認計畫並要求實作。

## 為什麼做

既有圖鑑已能辨識裝備等級、操練上限與科技等級，但只提供唯讀資訊。延續現有單檔修改器，開放有來源證據與隔離遊戲驗證的操作。

## 要改什麼

- 修改有效一般裝備庫／穿戴裝備的等級，保留品質、詞條與雙向歸屬；不處理寶物、內丹或生成實體。
- 調整職業操練上限，不取消進行中的操練，不得低於角色既有職業等級。
- 調整有效進階科技 ID 31–44，不取消研究或改動設施進程。
- 一般與超限模式分別驗證、開閘門；共用交易、預覽、還原、精確匯出與自訂座標限制。
- 編輯器升為 v2.1，知識維持 V1.0.10.2；本機 JS 補丁只做獨立提案。

## 影響範圍

核心／知識解析器、現有物品及山寨 UI、單檔 HTML／PWA、合成及隔離遊戲驗證、研究與維護文件。遊戲及玩家資料留在 repo 外，正式來源不改動。
