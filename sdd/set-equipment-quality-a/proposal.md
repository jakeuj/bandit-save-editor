# 套裝品質 A：靜態候選與驗證準備

類型：新功能。狀態：候選案，尚未授權實作。日期：2026-10-23。

## 為什麼做

把共同資格、交易及驗證準備拆成可續做切片，避免原生補證前擴大既有等級權限。

## 要改什麼

只做來源／最小資料、隔離候選資格、品質交易、獨立 oracle 與 manifest／proof 接線。四品質群組關閉；正式等級入口維持原已證明資格。候選測試不得修改正式權限或被正式入口選入。不啟動遊戲，不合併有效原生證明。

完整交易公式、雙池政策、四群組、19,440 基礎案／至少 864 效果組合及額外維度、原生基準與驗收界線依[母提案](../set-equipment-quality/proposal.md)，不以此摘要縮減範圍。[任務](tasks.md)為本階段唯一勾選來源。

## 影響範圍

知識生成器與最小規則模組、候選核心／合成測試、oracle、manifest、requirements／suite／migration；實際檔案依母提案，不提前新增 UI。

## 依賴與交付

A 完成只代表靜態候選就緒；沒有原生通過、跨池正式擴權或品質開閘。 B 依賴 A 全部完成；子案完成後回寫[母任務索引](../set-equipment-quality/tasks.md)。若工程切片超過一小時，先再拆子案；全量自動執行按 manifest 分片並記 checkpoint，不用縮分母達成時間目標。

本案自 2026-10-23 為目前主線，A1–A2 已授權；其餘逐段明確授權，原版桌面 UI 依當次明確授權。後續提交發布依當次有效授權，不把本次文件推送授權延伸為功能發布。
