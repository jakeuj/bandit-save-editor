# 遊戲改版按影響驗證

類型：重構。使用者已核准本方案並要求實作。

## 為什麼做

V1.0.11.2 對齊用了 15 副本、245 步驟、8 個遊戲 UI 案例，同一套 6,592 組公式重跑四次。高頻更新不應因整包指紋或 UI 摘要異動就全面重驗。

## 要改什麼

- 正式公告搭配靜態相依摘要選跑；預設 auto，保留 full、plan 與 resume。
- 相依語意未變沿用原始證據；相關疑慮只補隱藏原生測試。例行遷移 UI 未重驗不阻擋既有功能，computer use 僅依使用者明確要求。
- 公式去重、完成副本立即記錄、清理失敗保留告警；新版格式無法解析時保留既有發布版。
- 本機純知識更新跑相關 Node 與建置檢查，CI 保留完整發布檢查。新增寫入保留首次證明。

## 影響範圍

版本遷移與來源分析工具、共用建置證據閘門、合成測試、AGENTS／專案技能及維護文件。真實來源、存檔與原始結果留在 repo 外；不變更公開編輯 API，不發布。
