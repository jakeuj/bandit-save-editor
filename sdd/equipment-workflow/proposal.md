# v2.4 首次洗練選槽與背包裝備編輯

需求類型：新功能。已依使用者確認的計畫開始實作。

## 為什麼做

v2.3 只可修改裝備庫／穿戴裝備的已選洗練槽。讓背包普通裝備也能調整等級、係數及合法詞條，並將第一次選槽與洗練合成一筆可還原交易。

## 要改什麼

- 裝備 API 增加 plane=9，接受 z7／z9；背包只開原版等階1–9、品質1–6及原版等級，詞條限品質2–6。
- 首次選槽需要明確確認，原子修改目標旗標、ID與係數；已選槽不能更換，不扣魂魄。
- 使用庫別＋目前列號識別及還原；y0初始背包列號不重編。背包數量1、歸屬0；穿戴指標只指向z9。
- 新取得標記y24的0／1須另驗證並保留；未知狀態維持阻擋。品質、主係數、取得品質及歸屬不改。
- 新寫入分組證明，來源、規則及資料雜湊一致才開放。首次選槽另須原生遊戲選槽UI證據。
- 介面補位置篩選、明確目標與首次確認，保留單件效果預覽、兩入口匯出、整組還原及逐步復原。

## 影響範圍

核心、知識生成／建置驗證、裝備介面、隔離工具及合成測試；研究／維護文件與自建技能。編輯器v2.4，遊戲V1.0.10.2，V1.0.11.0測試分支只追蹤。

品質升降、增加槽位、重選已選槽、特殊裝備、批次、丹藥擴充與新超限不在本版。原始遊戲、存檔、狀態、截圖與log留repo外。保留開始前工作目錄的文件變更。
