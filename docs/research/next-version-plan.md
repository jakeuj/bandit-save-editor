- Mac 啟動、本機存讀與新程序重啟已於 2026-10-27 在 V1.0.13.0 與 V1.0.14.0 通過（[紀錄](macos-runtime-investigation.md#v10140-mac-驗證2026-10-27)）。V1.0.11.2／V1.0.12.2 只有靜態核對，正式分支已無法取得，不再補。遊戲 UI 的 Steam 雲存檔清單、真實雲端上傳與成就仍未驗。
- 有名角色與自然職業上限的 [runtime 補丁](../../sdd/runtime-patch/proposal.md)另列研究候選，與網站修改器分開。2026-10-27 決定：只限自用、Mac 隔離副本先行、有名角色採改 js 範本、資質移出範圍；自然職業上限靜態研究見[職業上限研究](job-level-cap.md)。
