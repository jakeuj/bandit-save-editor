# 高頻遊戲更新的驗證精簡

2026-10-23 使用者核准：按影響選跑，UI 顯示或互動疑慮可以等實際故障再複查，例行 computer use 為零。實作入口與參數見[維護指引](../maintenance/migration.md#版本遷移重驗)，規格及驗收見 [SDD](../../sdd/selective-migration/tasks.md)。

## 此次完整驗證的成本

V1.0.10.2 → V1.0.11.2 的原始結果見[當次紀錄](archive/v1.0.11.2-audit.md)：核對正式公告、解包 15 來源、15 份 Windows 副本／245 步驟／24 群組，品質公式 6,592 組各跑四次，再以桌面操作補六件品質與兩件選槽案例。最後 138 Node／12 headless 通過。清理鎖檔、除錯連線收尾與瀏覽器過濾器干擾造成額外重跑；這些不是每次改版都應重複的遊戲相容性檢查。

## 新工具的兩版重播

使用保留在 repo 外的舊版來源與正式安裝新包，只執行靜態規劃：

| 項目 | 舊流程 | 新選跑計畫 |
| --- | --- | --- |
| 原生副本 | 15 | 6，僅裝備相關 |
| 完整品質公式矩陣 | 4 次 | 0，語意未變 |
| 遊戲桌面案例 | 8 | 0 |
| 相同來源再執行 | 仍可全驗 | 0 副本，直接沿用 |

選中 `affix-replacement`、`equipment-workflow`、兩庫各升／降品四份副本，理由是相關庫別寫入及生命週期依賴異動；成長、進階修改、丹藥、基礎資質及技藝上限不需重跑。bound-reference、expression、物件及參數索引的移動已正規化；職業名稱／三語描述欄與已辨識顯示分支不當成公式變化。套裝合成的動態庫別是已核對的裝備領域例外，其他未知動態寫入仍保守納入相依。

這是選跑決策重播，沒有執行上述六份原生副本，也沒有操作遊戲桌面；不把規劃當成新版原生通過。保留 V1.0.11.2 原本完整實測證明，只新增與它綁定的語意基準。沒有重新發布網站。

## 證據及故障處理

- 舊版摘要繼續供原始 allowlist／首次證明使用；新版本 2 語意摘要用於遷移，避免改寫舊摘要冒充原生重驗。
- 複合證明逐項記錄原生、沿用及 UI 未重驗；沿用直接保留原始實測來源，UI 不填成通過。建置核對完整來源、規則、核心程式及每項相依。
- 完成副本即保存外部 checkpoint。續跑綁來源、工具、runtime、存檔及情境，並重查證據檔；未完成副本重試，清理錯誤只列告警。
- 不支援的來源格式保留待查報告及既有發布版，不自動擴大為桌面測試。新增可寫功能仍須獨立首次完整證明。

## 本輪驗收

合成案例涵蓋語意正規化、文案／顯示免跑、公式定向選跑、共用 IO 擴大、未知資訊拒絕沿用、規則變更、原始證據綁定、連續沿用、混合原生與沿用、建置回滾、續跑／鎖檔、公式去重及 ZIP64 選取快取。完整發布檢查結果另記於 SDD，不把測試數量當成永久基線。

本輪 `npm run verify:release` 通過 152 Node／12 headless；新的 `npm run verify:knowledge` 通過 27 Node，本機 Node 24.14.0 約 2.39 秒。後者供純知識更新的本機檢查，受影響功能另補相關測試，CI 仍跑完整發布驗證。
