## 2. 結丹丹藥與內丹：先做唯讀依賴

`角色资质上限倍率` SID **358500068340403**，expressions **4058–4060** 仍由角色 y50 的整數次數，逐次讀 `z16[角色,2k]` 引用的 `z17[內丹,15]`，最後加 1.5。

`内丹属性计算` SID **709738476735942**，expressions **5380–5381** 另經同一引用讀內丹範本、等級、等階、主係數及品質，再呼叫裝備主屬性公式。因此 **A 與 M 同時受內丹影響**，不能只擴大 cap 倍率。

`渡劫结束` SID **248151541683973** 的成功分支 **963468871617308** 會搬移入體、清除角色裝備欄、改角色等級及 y50、寫 z16 品質／內丹引用與 z17 owner；子事件 **448872290783748** 寫 z17 y9–11 為 107–109、y15–17 為結丹資質提升係數。`内丹入体存入` SID **602328981829577**／子事件 **905333709115389** 搬移 z9→z17 的 y0–49。這是跨層交易，不是獨立 y6 修改。

**新查證：** `获得内丹经验` SID **993397580653400** 的事件本體無 actions／children；`内丹升级经验` SID **717223484505453** 有 expression **3649** 的需求公式，但本輪掃描事件樹中的直接函式 action 與 expression 綁定引用，兩函式呼叫數均為 0。這不涵蓋任意動態名稱呼叫，因此只能說本輪未找到可用經驗流程；不可因存在需求公式而新增經驗編輯器。

下一切片先輸出唯讀 A、M、C 與每筆引用來源，拒絕缺列、錯類型、owner 不符、重複／越界引用，再與原生函式對照。結丹丹藥可先只改 B；內丹品質、渡劫成功狀態及階段跳轉各自另案。後續驗證需要成功／失敗分支、存讀／重啟及再次結丹；本輪沒有執行。

### 實作摘要（2026-10-24，v2.16 結丹角色丹藥）

依[輕量開發流程](../maintenance/lightweight.md)實作，只開丹藥入口，不建 SDD。對話決定：穿戴限制在新旗標下放寬為逐件檢查；基礎資質與天賦對結丹角色維持拒絕（v2.17 已開放，見下一節）；冒煙以同一角色結丹 2 次。

**靜態核對（V1.0.11.2）**：
- `角色资质计算` 為 round(100×(A+B/10))/100。A＝`属性计算(c,104–106)`，也就是原始/10＋天賦＋`内丹属性计算`＋`装备属性计算`。
- `角色资质上限` 為 C＝round(100×(A×M))/100。
- M＝1.5＋Σ_{k=1..y50} z17[z16[c,2k],15]：從 0 依 k 順序加總，最後才加 1.5。兩次 0.8、1.68 得到 3.98；若寫成 1.5+0.8+1.68 會得到 3.9799999999999995。
- `结丹资质提升系数(q,k)` 為 round(100×1.2^(k−1)×(0.4+(k+q−2)×0.2))/100。
- `境界上限`＝9，且要求 y50+1<9，所以 y50 為 0–8；`渡劫结丹品质` 為 1–9。
- `内丹属性计算` 只累加入體內丹 wp 範本的主屬性，不算詞條。本版 81 個內丹範本、所有裝備／寶物範本、詞條池與套裝效果都沒有 104–106，因此 **A 實際不受內丹與穿戴影響，只有 M 隨結丹改變**；萬一出現就拒絕，不模擬主屬性公式。

**欄位與入口**：仍只寫 `[角色,13–15,2]`，入口沿用 `pillInfo`／`setPillAptitudeBonus`，還原群組 `aptitude:角色ID`。
- 新旗標 `pillAptitudeBonusAscended`（batch2 family），冒煙通過後已開。
- 旗標關閉時與 v2.13 完全相同。
- 開啟後，`characterAptitudeSource` 只在丹藥入口改走 `ascensionRecord`（讀結丹紀錄、算 M）與 `aptitudeNeutralEquipment`（逐件穿戴檢查）。
- 開啟後 cap 改用原式括號 `100×(A×M)`；`pillInfo` 多回傳 `multiplier`、`ascensions`，UI 顯示「結丹 n 次，倍率 M」。
- 基礎資質與天賦不傳 `ascended`，對結丹角色照舊拒絕。

**拒絕條件**：
- y50 不是 0–8 的整數。
- 前 y50 對品質不是 1–9 的整數，或列號越界／重複。
- 第 y50+1 到 8 對仍有資料。
- 被引用的 z17 有下列任一情況：
  - y1 不是內丹範本，或同範本重複。
  - y7 ≠ 角色。
  - y9–11 ≠ 107–109。
  - y15–17 ≠ 係數公式。
  - 範本主屬性含 104–106。
- 穿戴件有下列任一情況：
  - 列號越界、owner／部位不符，或範本未辨識。
  - 主屬性、存檔詞條 ID（y9–14）或套裝效果含 104–106。
  - owner 指向角色卻未穿戴。
- 其餘沿用 v2.13。z17 未被引用的殘留列**不拒絕**，原因見下方冒煙。

**合成測試**：

  - 兩次結丹的端點與下一步。

  - 重生殘留列。
