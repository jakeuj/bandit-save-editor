# 各版功能與驗收紀錄

以下保留各版交付時的能力、限制與驗證範圍；例如 v2.8 的「天賦唯讀」是當時狀態，v2.9 的新增能力見後續章節。現況入口見 [README](../README.md)；新工作依各功能研究與 SDD，不沿用歷史授權。

## v2.19 城牆強化等級

發布日期：2026-10-24；遊戲知識基準：V1.0.11.2。

「山寨與科技」新增城牆強化等級 `[19,1,0]`：可設為 0 到原版上限（(城牆建築等級+1)×60），不扣除或退還強化貨幣，也不動城牆建築等級。原版 `城墙升级` 不改目前生命，而回血與採集治療都只補到最大生命、沒有流程會往下壓；所以降級時，目前生命若超過新等級不含加成的最大生命就一起下修（科技與司職加成無法離線算準，這個下界一定不會高於實際上限），由遊戲回血補回；升級不改生命。新旗標 `wallEnhancementLevel`；城市層數與聲望不在本版範圍。

證據：依[輕量流程](maintenance/lightweight.md)一次隔離遊戲冒煙：
- 固定基準存檔 60→30，雲存檔載入、原版存檔、新 PID 讀回一致。
- 讀回後原生升級 30→31 扣強化貨幣、生命不變，放行時間後回血到原生上限以內。
- 第二輪原版存檔與修改器重讀一致；新程序讀回時引擎多一次原生回血（載入到凍結前），屬預期。

加成大於 0 的存檔、城牆建築等級大於 0 與戰鬥中存檔沒有原生跑過。實作摘要見[集中研究](research/candidate-sweep-2026-10-23.md#實作摘要2026-10-24v219-城牆強化等級)。

## v2.18 結丹角色技藝上限

證據：依[輕量流程](maintenance/lightweight.md)一次隔離遊戲冒煙：沿用 v2.16 原生備料的結丹存檔，角色 8 一次升三項、降一項上限，雲存檔載入、原版存檔、新 PID 讀回一致；修改器重讀遊戲寫出的存檔仍有共同生成見證。依使用者決定沒有跑原生技藝經驗。實作摘要見[集中研究](research/candidate-sweep-2026-10-23.md#實作摘要2026-10-24v218-結丹角色技藝上限)。

## v2.2 新功能範圍

「物品與裝備」可修改普通裝備已選洗練槽係數，最多兩位小數；係數操作保留詞條ID與洗練旗標。僅原版等階1–9、品質2–6及等級範圍，排除套裝、寶物、內丹及未知特殊狀態。v2.4另開放z7背包及首次選槽交易；超限係數仍未開放。

「角色養成」可直接設定三項丹藥累積增量，1等於資質0.1點，可下調或歸零，不扣丹藥。選擇已持有的對應丹藥作為上限依據；上限納入角色天賦，先支援無結丹及重生階段紀錄、穿戴來源可核對的角色。有名範本須與載入資料一致，一般隨機角色使用存檔資質。原生服藥可能產生小數增量，這類既有值先保持唯讀；重生依原版清零。

詳細來源、12組通過案例、後續操作及限制見[第二批實作與驗證](research/advanced-editing-batch2.md#v22-實作與隔離驗證)。

## v2.3 精準洗練

在「物品與裝備」選擇裝備與已洗練槽，搜尋合法詞條；預設保留目前係數，也可輸入原版範圍內最多兩位小數的值。確認舊／新詞條與單件效果後，按「套用詞條與係數」。預覽包含這件裝備相同屬性的主屬性及其他詞條，不代表角色完整面板。

精準洗練不新增槽位或重複詞條，不修改品質、取得參數、選槽旗標或穿戴歸屬；首次選槽另由v2.4確認，品質升降另由v2.5交易處理。等級、係數與詞條共用整件裝備還原群組，復原一步則回到上一筆交易。已通過範圍、原生公式與驗證限制見[精準洗練研究與實測](research/precise-affix-editing.md)。

## v2.4 背包裝備與首次洗練選槽

背包普通裝備可修改等級、係數與合法詞條；未洗練裝備可勾選首次確認，將選槽旗標、詞條與係數一次套用。已有選槽不能更換，品質與特殊裝備限制維持。遊戲選槽UI、隔離存檔／重啟、桌面／390px精確匯出及PWA離線／版本交接已通過，首次選槽已開啟；範圍與正式部署證據見[裝備操作補完](research/equipment-workflow.md)。直接file://新流程仍待人工驗收。

## v2.5 普通裝備品質升降

「物品與裝備」可調整背包、裝備庫與穿戴普通裝備的Q1–Q6品質。升品須明選每個新增尾槽的合法詞條，降品須確認移除尾槽；等級超過目標上限、或已選洗練槽會被移除時阻擋。係數保留原品質區間的相對位置，不重抽、不扣資源；取得參數y23、標記、鎖定與歸屬保留。

預覽顯示品質、等級上限、主副係數、槽位及單件裝備效果；手機比較表可左右捲動。品質與等級、洗練一起還原，逐步復原回到前一筆交易。一般主係數區間外、套裝、寶物、內丹與超限保持停用。完整限制與獨立驗證見[品質研究與實測](research/equipment-quality.md)。

## v2.6 批次操作

每批只執行一種動作。角色可選全部或跨頁勾選；職業只含單角色已習得項目，不藉經驗解鎖，須先關閉自動轉職。九項技藝依各自上限結算。裝備一次選背包或裝備庫，僅普通裝備升至各自原版上限，預設不含穿戴者，超限裝備不會自動降級。科技輸入存檔值，遊戲Lv為此值加一，仍檢查研究狀態與容量。

先檢視變更／無變更／範圍外／阻擋摘要；所有目標合格才整批套用。一次批次只增加一筆歷史，復原一步回到批次前；個別還原仍以同項經驗或整件裝備的累計修改回到載入基準。完整尺寸合成測試、桌面與390px精確下載、Mac隔離原生存檔及新PID讀回已通過，詳細範圍見[批次操作驗收](../sdd/batch-editing/tasks.md)。直接file開檔與正式部署不列為本輪已驗收。

## v2.8 一般隨機角色九項技藝上限

「角色養成」提供九項上限輸入與整組預覽，逐項列出上限、等級及經驗餘額的前後值；輸入或存檔變更後須重新預覽，套用時再次檢查。僅支援已招募、範本 0、非在監、無結丹／重生階段紀錄的一般隨機角色。九項目標須與目前品質、原始資質及三項天賦符合共同的原版招募傾向與主副技藝條件；有名角色因載入／數值更新會依範本回填而停用。

上限不能低於現有等級；降低至現有等級但仍有經驗餘額也會阻擋。提高上限保留等級與餘額，不立即升級、不自動清零。九項一起確認，只寫真正變更的上限 token；不提供天賦編輯、超限、角色生成或代做轉職。

首次有效上限變更後，同角色九項上限、等級與餘額共 27 欄累計一起還原，包含之前及之後的單項／全部技藝經驗操作；其他角色不受影響。「還原」回載入基準，「復原一步」回上一筆操作，「還原全部」也可復原一步。

正式隔離 suite 已通過完整 108 角色矩陣、批次後原生成長及 13 階段生命週期，每個必要階段均有原版存檔與新 PID 重啟讀回；來源及基準原檔雜湊保持不變。實測確認剛達上限保留餘額，下一次已封頂取得經驗才清零；提高上限保留當時等級與餘額。

獨立證明已合併，九項上限已開放；原有 23 群組證明完整保留，現共 24 群組，天賦維持唯讀。`npm run verify:release` 通過 138 項 Node、12 項 headless，沒有失敗或略過；新增 5 案以正式開放的建置驗證桌面／390px、直接 file、PWA 離線與更新交接，實際下載 bytes 及重載均通過。完整驗收紀錄見 [B 階段任務](../sdd/random-character-skill-caps-b/tasks.md)。功能提交`023b4f4`已完成Pages部署與正式站核對，詳見[發布證據](research/random-character-skill-caps.md#v28-正式發布驗證)。
