# 山寨帳房

《塔防山賊模擬器》的繁體中文存檔修改器。使用瀏覽器讀取 `.dat`，修改後匯出副本；存檔全程在本機處理。

**[開啟修改器](https://jakeuj.github.io/bandit-save-editor/)**

## 功能

- 修改銅錢、共用經驗、魂魄、科技點與操練點。
- 搜尋、篩選與批次修改遊戲材料資料表中的 220 筆材料。
- 比對兩份原始存檔，顯示不同欄位、座標與差額，並匯出 CSV。
- 使用自訂座標加入常用欄位，支援欄位設定匯入與匯出。
- 檢視變更、逐項還原、復原一步，或還原全部修改。
- 下載原檔備份與修改副本；只替換指定數值，保留其他原始 JSON 文字。

## 使用方式

1. 開啟網站，選取遊戲 `save` 資料夾內的存檔，例如 `ea3save.dat`。
2. 修改資源或材料，從「檢視變更」確認內容。
3. 先下載原檔備份，再匯出修改存檔，例如 `ea3save.modified.dat`。
4. 結束遊戲，把原始存檔另行備份，將修改副本改回原檔名並放回 `save` 資料夾。
5. 重新開啟遊戲，載入對應存檔確認。

也可從網站下載單一 HTML，之後使用 Edge 或 Chrome 離線開啟。離線檔的圖示可以省略，修改功能不依賴外部檔案。

## 已核對的資料欄位

座標從 0 起算。

| 項目 | JSON 位置 |
| --- | --- |
| 銅錢 | `data[1][2][0]` |
| 共用經驗 | `data[2][2][0]` |
| 魂魄 | `data[3][2][0]` |
| 科技點 | `data[4][2][0]` |
| 操練點 | `data[5][2][0]` |
| 材料數量 | `data[材料編號][6][0]` |

材料名稱取自遊戲資料表；部分資料為重複名稱或占位名稱，不代表遊戲內都已開放。共用經驗與角色、職業、技藝經驗各自儲存。

目前依據 2026-10-19 的遊戲資料與三維陣列存檔格式製作。已以實際存檔驗證讀取、比對及匯出，尚未在遊戲內載入驗證。遊戲更新後可能需要重新核對欄位。

## 本機開發與驗證

本專案沒有套件相依、後端或建置步驟，直接開啟 `index.html` 即可使用。要執行核心驗證，使用 Node.js 18 或更新版本：

```sh
node --test tests/save-core.test.cjs
```

測試使用合成存檔資料，驗證指定欄位的精確輸出、未修改內容保留、復原、錯誤格式與數值界限。

## GitHub Pages

GitHub Pages 的來源為 `main` 分支根目錄，`.nojekyll` 停用 Jekyll 處理。推送 `main` 後由 GitHub Pages 自動部署。

網站入口為 `index.html`。搜尋與分享資訊設定在 HTML `<head>`，可編輯的分享圖片來源為 `assets/social-card.svg`，對外提供 `assets/share-card-v1.png`。

本 repository 不含玩家存檔、比對報告或完整遊戲程式。
